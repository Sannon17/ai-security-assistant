# AI Security Log Analyser

An AI-powered tool that automatically analyses security logs, 
identifies MITRE ATT&CK techniques, rates severity, and generates 
timestamped incident reports.

## Usage
python3 chat.py <logfile>

## Example
python3 chat.py sample.log

## Technologies
Python · Groq API · LLaMA 3.3 · Sysmon logs · MITRE ATT&CK

## Versions
- v0.1 — AI security assistant (Q&A)
- v0.2 — Automated log analysis with report saving  
- v0.3 — Analyse any log file via command line
